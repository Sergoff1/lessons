```java
public static int findMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```
Тройка Хоара для функции `findMax(int[] arr)`:  
`{P: arr.length > 0} findMax(arr) {Q: result = max(arr)}`

Определим инвариант цикла:  
`I: 1 <= i < arr.length AND res = max(arr[0]..arr[i])`  
i указывает на проверяемый элемент, а res содержит максимальное значение из просмотренной части массива в диапазоне от 0 до i.

Доказательство инварианта.  
1. Инициализация:  
   До начала первой итерации цикла: i = 1 и res = arr[0]  
   Проверка инварианта: `1 <= i < arr.length AND res = max(arr[0]..arr[0])`  
   Инвариант истинен в начале.  

2. Сохранение инварианта:  
   Предположим, что инвариант истинен до некоторой итерации цикла, где `1 <= i < arr.length AND res = max(arr[0]..arr[i])`  
   Во время выполнения цикла: `res = max[arr[0]..arr[i]] AND i = i + 1 `
   После итерации: i увеличивается на 1, следовательно, `i = i + 1`  
   `res = max(max(arr[0]..arr[i-1]), arr[i]) = max(arr[0]..arr[i])`  
   Таким образом, инвариант по-прежнему истинен: `0 <= i < arr.length AND res = max(arr[0]..arr[i])`  

3. Завершение:  
   Цикл завершается, когда i становится равным arr.length  
   На этом этапе `res = max(arr[0]..arr[arr.length - 1])`, так как инвариант после последней итерации: `i = arr.length - 1 AND res = max(arr[0]..arr[arr.length - 1])`  
   Следовательно, постусловие выполняется: `res = max(arr)`.   

Получается, что функция `findMax(arr)` корректно вычисляет максимальное значение массива, что подтверждается нашей инвариантной логикой и тройками Хоара.
