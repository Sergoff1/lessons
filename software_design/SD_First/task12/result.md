```java
private static int max(int a, int b) {
    return a > b ? a : b;
}

private static int abs(int x) {
    return x > 0 ? x : -x;
}

public static int maxAbs(int a, int b) {
    return max(abs(a), abs(b));
} 
```

Для начала докажем корректность функций max(a, b) и abs(x). 

Функция `abs(x)`:  
`{P: x = n} abs(x) {Q: x = |n|}`

Шаги Доказательства:

1. Предположим, что предварительное условие P истинно до выполнения функции abs(x). То есть, x = n(целое число в диапазоне int).
2. Далее выполняется тело функции:

`x > 0 ? x : -x`

После выполнения данной строки переменная x может поменять свой знак.  
Если исходное значение x было отрицательным, то после выполнения данной строки
значение переменной x станет положительным, иначе оно не изменится.

Теперь проверим постусловие после выполнения функции:  
Постусловие `Q: x = |n|`.  
Именно это условие будет истинным после выполнения оператора `x > 0 ? x : -x`.

Функция `max(a, b)`:  
`{P: a = n, b = m} max(a, b) {Q: res = max(n, m)}`

Шаги Доказательства:

1. Предположим, что предварительное условие P истинно до выполнения функции max(a, b). То есть, a = n(целое число в диапазоне int), b = m(целое число в диапазоне int).
2. Далее выполняется тело функции:

`a > b ? a : b`

После выполнения данной строки мы получаем наибольшее значение из пары.  
Если исходное значение `a > b`, то после выполнения данной строки получим `a`, иначе -- `b`.

Теперь проверим постусловие после выполнения функции:  
Постусловие `Q: res = max(n, m)`.  
Именно это условие будет истинным после выполнения оператора `a > b ? a : b`.  


Корректность функций доказана, теперь докажем корректность композитной функции `maxAbs(a, b)`:  
`{P: a = n, b = m} maxAbs(a, b) {Q: res = max(|n|, |m|)}`

Шаги Доказательства:

1. Предположим, что предварительное условие P истинно до выполнения функции maxAbs(a, b). То есть, a = n(целое число в диапазоне int), b = m(целое число в диапазоне int).
2. Далее выполняется тело функции, путём вызовов корректных методов `max` и `abs`:

`max(abs(a), abs(b))`.

После выполнения данной строки мы получаем наибольшее значение из пары по модулю.   
Если исходное значение `|a| > |b|`, то после выполнения данной строки получим `|a|`, иначе -- `|b|`.

Теперь проверим постусловие после выполнения функции:  
Постусловие `Q: res = max(|n|, |m|)`.  
Именно это условие будет истинным после выполнения оператора `max(abs(a), abs(b))`.
